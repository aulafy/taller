# Seguridad

## Informar de una vulnerabilidad

No publiques credenciales válidas, datos personales ni detalles que faciliten explotar un ejemplo desplegado.

Envía el informe a **learntouseai@gmail.com** con:

- carpeta o versión afectada;
- impacto observado;
- pasos mínimos de reproducción sin datos sensibles;
- mitigación temporal si existe.

## Alcance educativo

Los ejemplos enseñan controles y fallos en entornos locales o desechables. No autorizan pruebas sobre sistemas ajenos. Las aplicaciones de demostración no deben considerarse listas para tratar datos reales sin una revisión específica de seguridad, privacidad y operación.

## Secretos accidentales

Si una clave válida entra en Git, se considera comprometida aunque el archivo se borre después. Revócala o rótala en el proveedor, actualiza los entornos afectados y revisa el historial antes de publicar una corrección.
