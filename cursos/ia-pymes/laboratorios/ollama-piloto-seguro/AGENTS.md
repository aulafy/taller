# Reglas del laboratorio

- Trabaja solo con datos sintéticos incluidos en esta carpeta.
- No añadas claves, documentos de empresa ni llamadas a servicios cloud.
- La URL de Ollama debe ser local (`localhost`, `127.0.0.1` o `::1`).
- No elimines el bloqueo de destinos remotos para “hacer funcionar” una prueba.
- No fijes una cifra universal de RAM, velocidad o calidad: conserva las métricas observadas.
- Si cambias el comportamiento, actualiza las pruebas y `docs/VERIFICADO.md`.
- No expongas el puerto 11434 ni añadas túneles, proxies o reglas de firewall.
