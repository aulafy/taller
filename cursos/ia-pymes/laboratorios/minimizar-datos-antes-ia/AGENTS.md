# Reglas del laboratorio

- Utiliza únicamente el conjunto sintético incluido.
- No pegues datos personales, documentos, nóminas, facturas ni enlaces reales.
- El archivo `salida/mapa-local.json` queda ignorado: nunca debe subirse ni enviarse al modelo.
- No llames “anónima” a la salida; es una copia minimizada y seudonimizada para este ejercicio.
- No añadas red, telemetría, claves ni dependencias externas.
- Ejecuta `npm run verificar` antes de proponer cambios.
