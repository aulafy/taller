# Reglas del laboratorio

- Trabaja solo con los datos sintéticos incluidos.
- No sustituyas los identificadores `DEMO` por clientes, facturas, nóminas o personas reales.
- Conserva el error silencioso de la columna «propuesta IA»: forma parte del reto.
- La solución se demuestra con fórmulas nativas, casos conocidos y conciliación independiente.
- No añadas llamadas de red, claves, telemetría ni dependencias externas.
- Ejecuta `npm run verificar` antes de proponer cambios.
