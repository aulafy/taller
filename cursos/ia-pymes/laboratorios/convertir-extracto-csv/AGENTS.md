# Reglas del laboratorio

- Utiliza únicamente movimientos e identificadores `MOV-DEMO`.
- No añadas cuentas, comercios, extractos ni saldos reales.
- La propuesta incorrecta debe seguir fallando: forma parte del reto.
- No corrijas una diferencia cambiando el saldo; localiza la fila o transformación responsable.
- Conserva el catálogo cerrado y rechaza columnas, filas o categorías adicionales.
- No añadas red, claves, telemetría ni dependencias.
- Ejecuta `npm run verificar` antes de proponer cambios.
