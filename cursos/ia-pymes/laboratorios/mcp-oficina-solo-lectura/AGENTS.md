# Instrucciones para agentes

- Mantén el laboratorio local, sintético y de solo lectura.
- No añadas datos personales, credenciales, red ni herramientas con efectos.
- Toda tool nueva necesita esquema estrecho, límite, anotaciones y pruebas.
- No escribas en stdout desde el servidor: está reservado para JSON-RPC.
- Ejecuta `npm run verificar` antes de proponer cambios.
- Actualiza la fecha y las versiones solo después de volver a probar el laboratorio.
