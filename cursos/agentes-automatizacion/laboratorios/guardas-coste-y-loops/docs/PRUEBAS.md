# Matriz de pruebas

| Prueba | Garantía |
|---|---|
| Fingerprint estable | El orden de argumentos no evita detectar repetición |
| Reserva/reconciliación | Se bloquea antes y se factura después con uso real |
| Flujo sano | Las guardas no detienen todo |
| Loop | Tercera repetición bloqueada |
| Presupuesto | Llamada cara no llega al proveedor |
| Cuota de tool | Límite específico |
| Pasos y tiempo | Dos límites independientes |
| Sin progreso | Consumir sin cambiar estado se detiene |
