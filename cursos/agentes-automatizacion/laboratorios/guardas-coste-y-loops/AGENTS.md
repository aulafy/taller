# Instrucciones para agentes

- No añadas llamadas reales, claves ni tarifas presentadas como vigentes.
- Toda nueva guarda necesita un escenario que la active y otro que no.
- Usa enteros para dinero; documenta siempre la unidad.
- La decisión de bloqueo ocurre antes de ejecutar la acción.
- Conserva la prioridad de motivos para que las pruebas sean deterministas.
- Ejecuta `npm run verificar` antes de publicar.
