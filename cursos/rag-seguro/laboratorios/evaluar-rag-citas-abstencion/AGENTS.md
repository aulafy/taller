# Instrucciones para agentes

- Conserva todos los datos como sintéticos.
- El filtro de tenant y cuarentena debe ejecutarse antes del ranking.
- Una cita válida debe existir, haber sido recuperada y pertenecer al tenant autorizado o al corpus público.
- No conviertas la solución en una llamada obligatoria a un proveedor.
- Toda métrica nueva necesita al menos un caso positivo y uno negativo.
- Ejecuta `npm run verificar` y `npm run evaluar` antes de publicar.
