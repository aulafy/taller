# Alcance para agentes

- Mantén el laboratorio determinista, offline y sin dependencias.
- Usa únicamente datos, dominios y credenciales ficticios.
- No conviertas el detector de palabras en la frontera de seguridad.
- Toda nueva tool debe declarar efecto y riesgo.
- Todo nuevo escenario debe indicar contrato, procedencia y resultado esperado.
- Ejecuta `npm run verificar` antes de publicar.
