# Instrucciones del laboratorio

- Conserva la API pública cubierta por `test/tasks.test.mjs`.
- No añadas dependencias ni cambies `package.json`.
- No desactives, borres ni debilites pruebas para conseguir una salida verde.
- Reduce código redundante en `src/tasks.mjs`; no reescribas el proyecto entero.
- Ejecuta `npm test` antes y después del cambio.
- El trabajo termina cuando `npm test` y `npm run auditar` pasan.
- Revisa `git diff -- src/tasks.mjs` y explica cada eliminación.
