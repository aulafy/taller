# Ejemplos del curso «Agentes en producción»

Código y laboratorios vinculados a las lecciones de agentes fiables: estado, herramientas, evaluación, observabilidad, privacidad y revisión humana.

## Laboratorios disponibles

### [Observabilidad de agentes con Ollama y Langfuse](./laboratorios/observabilidad-agentes-ollama/)

Laboratorio en Python con Ollama, Langfuse, RAG sintético y una herramienta de solo lectura. Enseña a crear y diagnosticar una traza antes de conectar servicios reales. Su estado es **borrador verificable**: la estructura se comprueba sin red, pero falta registrar una ejecución manual con un entorno configurado.

## Principio de seguridad

No uses esta carpeta para enviar, publicar, cobrar, borrar ni modificar datos de un sistema externo. Empieza por evidencia sintética, permisos mínimos, límites de llamadas y revisión humana.
