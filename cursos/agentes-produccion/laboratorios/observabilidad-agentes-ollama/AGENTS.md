# Reglas del laboratorio

- Conserva los datos sintéticos del laboratorio. No añadas conversaciones, documentos ni credenciales reales.
- El código debe seguir funcionando con Langfuse Cloud o una instancia self-hosted mediante variables de entorno.
- No automatices la creación de cuentas, proyectos o claves de Langfuse.
- Antes de marcar el ejemplo como `verificado`, ejecuta tanto las comprobaciones automáticas como una traza manual y registra el entorno real en `docs/VERIFICADO.md`.
