# Brief verificable: Nexo Claro Legal

## Estado

Proyecto educativo. Despacho, equipo y datos completamente ficticios. No presta servicios jurídicos.

## Persona y problema

Una persona que gestiona una pequeña empresa quiere orientarse ante una duda contractual, societaria o laboral. Necesita saber si la temática encaja, entender cómo empieza el proceso y solicitar una conversación sin publicar detalles sensibles.

## Resultado de la versión 1

En menos de dos minutos, la persona identifica un área aproximada, entiende que todavía no existe relación profesional y puede preparar un contacto con datos mínimos.

## Incluido

- Inicio con propuesta, situaciones reconocibles, proceso resumido y límites.
- Tres áreas ficticias explicadas en lenguaje corriente.
- Proceso en tres etapas, preparación segura y orientación ante urgencias.
- Contacto con nombre, correo, organización opcional, categoría y canal preferido.
- Ausencia deliberada de textarea, adjuntos o relato libre.
- Preparación local de un correo mediante `mailto:`; sin envío automático.
- Privacidad específica del prototipo.
- Metadata, canonical, Open Graph, `LegalService` JSON-LD, sitemap y robots.

## No incluido

- Valoración jurídica, presupuesto o aceptación del encargo.
- Garantías de resultado, porcentajes, clientes, casos, reseñas o premios.
- Nombres, fotografías, colegiaciones o credenciales profesionales.
- Documentos, hechos del asunto, identificadores o categorías especiales de datos.
- Base de datos, analítica, cookies, chat, pago, firma o área privada.
- Atención urgente, cómputo de plazos o sustitución de canales oficiales.

## Restricciones

- HTML, CSS y JavaScript sin dependencias ni llamadas de red.
- Móvil primero desde 320 px y zoom al 200 %.
- Utilizable con teclado, foco visible y movimiento reducido.
- Todas las páginas deben identificar el carácter ficticio.
- El formulario debe explicar sus límites antes del primer campo.
- La interfaz no debe aparentar que el envío crea una relación profesional.

## Criterios de aceptación

- [x] Todas las páginas contienen un aviso visible de demostración.
- [x] La navegación es semántica, consistente y muestra la página actual.
- [x] Existe un único `h1` por página y un enlace de salto funcional.
- [x] No hay desplazamiento horizontal a 320 o 390 px.
- [x] Las áreas describen situaciones y límites, no resultados prometidos.
- [x] El proceso diferencia orientación, propuesta y posible encargo.
- [x] El contacto no contiene textarea, carga de archivos ni campo para el caso.
- [x] La preparación del correo no transmite ni persiste información.
- [x] JavaScript desactivado conserva contenido, navegación y contacto alternativo.
- [x] Los enlaces locales existen y `npm test` termina correctamente.
