# Instrucciones del caso

- Este ejemplo representa un negocio ficticio y usa datos sintéticos.
- Lee `docs/BRIEF.md` y `docs/PRUEBAS.md` antes de modificar código.
- Mantén HTML, CSS y JavaScript sin dependencias externas.
- No conviertas la solicitud de reserva en una confirmación de disponibilidad.
- No añadas testimonios, premios, descuentos urgentes ni fotografías que parezcan reales.
- Conserva navegación, formularios y mensajes accesibles por teclado.
- Ejecuta `npm test` y revisa 390 px y 1440 px antes de marcar un cambio como verificado.
- Si cambian rutas, datos o comportamiento, actualiza README, pruebas, sitemap y JSON-LD.
