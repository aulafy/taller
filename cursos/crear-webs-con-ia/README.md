# Ejemplos del curso «Crea webs profesionales con IA desde cero»

Código, casos completos y laboratorios vinculados al curso de Aulafy.

## Casos completos previstos

### Restaurante ficticio — itinerario inicial

Web móvil con contenido realista pero sintético, carta accesible, horarios, SEO local, solicitud de reserva, Vercel y dominio de demostración. Se construirá por etapas verificables sin fingir disponibilidad ni reseñas.

### SaaS ficticio — itinerario avanzado

Aplicación Next.js con una tarea central, autenticación, Supabase, RLS, estados, aislamiento entre usuarios, preview y producción. Pagos y automatizaciones quedarán fuera hasta disponer de requisitos y pruebas específicos.

## Laboratorios previstos

Los diez laboratorios del módulo 8 cubrirán prompts vagos, interfaz genérica, responsive, servidores duplicados, build de producción, formularios y RLS, rendimiento RLS, secretos, entornos y deuda técnica.

Cada carpeta se incorporará a `catalogo.json` cuando exista una versión ejecutable. Ningún proyecto se marcará como verificado por el mero hecho de compilar.
